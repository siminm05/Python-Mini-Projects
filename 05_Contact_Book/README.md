# Contact Book 📞
A simple command-line Contact Book application built in python.
This project allows users to manage contacts through a menu driven interface


### Features:
1. Add new contact
2. View all contacts
3. Delete an existing contact
4. Edit a contact
   - Edit Name
   - Edit Phone Number
5. Search contacts using partial names


### Additional:
- Phone number validation
- Prevent empty contact names
- Menu input validation


### Concepts practiced:
- functions
- lists
- dictionaries
- CRUD operations
- loops
- conditional statements
- input validation
- exception handling
- string methods:
  - strip()
  - lower()
  - isdigit()

 
### Future improvements: 
1. save contacts to a file
2. load contacts automatically
3. store multiple phone numbers
4. add email addresses
5. export contacts to CSV
