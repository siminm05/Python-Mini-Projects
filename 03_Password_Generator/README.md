# Password Generator
A command-line Python utility that generates customizable passwords based on user-defined lengths, quantities, and character types

### Features:
1. Customize character sets: Include lowercase, uppercase, digits, and special symbols
2. Bulk generation: Create multiple passwords at the same time
3. Input validation: Handles typos and incorrect inputs smoothly without crashing

### Concepts Used:
- Loops and control flow
- Functional programming
- String manipulation
- Exception handling
- Nested loops
