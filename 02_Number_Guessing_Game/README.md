# Number Guessing Game
A simple project built with Python. The player selects a difficulty level and tries to guess the randomly generated number between 1 and 100 within a limited number of attempts 

### How it works:
1. Select a difficulty level:
   - easy - 10 guesses
   - medium - 7 guesses
   - hard - 5 guesses
2. The program generates a random number between 1 and 100
3. Enter your guesses
4. The game gives feedback:
   - Too low!
   - Too high!
   - Spot on!
5. The game displayed the number of guesses remaining
6. Once the guesses run out, the game ends
7. You can choose to play another round

### Concepts used:
- python functions
- random module
- if/elif/else statements
- try/except for input validation
- user input
- basic game logic
