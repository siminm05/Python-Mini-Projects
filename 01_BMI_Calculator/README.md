# BMI Calculator
A simple python BMI calculator that accepts different weight and height units -> converts them to standard units -> calculates BMI -> displays the corresponding BMI category

### Features:
1. accepts weight in:
   - kilograms - kg
   - pounds - lb
2. accepts height in:
   - meters - m
   - centimeters - cm
   - feet and inches - ft
3. converts entered values to kilograms and meters before calculation
4. validates user input
5. handles invalid numeric input using 'try/except'
6. displays BMI rounded to one decimal place
7. allows the user to calculate multiple BMIs in one session


### BMI Category
- below 18.5 - underweight
- 18.5 to 24.9 - normal weight
- 25 to 29.9 - overweight
- 30 or above - obese
